# XpBank
Xp Banking Minecraft Plugin.

This is a minecraft plugin for 1.20+ that adds a bank for storing XP.

Dependencies: Vault

https://www.zrips.net/cmivault/

Commands:

- /xpb bal | balance
- /xpb deposit
- /xpb withdraw
- /xpb pay
- /xpb admin give player amount
- /xpb admin remove player amount

It's Open Source :D
